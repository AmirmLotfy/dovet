# Dovet

Use Dovet when the user asks to protect, checkpoint, inspect or recover coding work.

Begin with `dovet_status`. If the service is unavailable, explain that the independent local
service must be initialized and started. Never claim protection is enabled from plugin presence
alone.

Automatic interruption and recovery apply only to Dovet-managed runs. Treat existing Codex
Desktop tasks as observed work unless the user explicitly starts a new managed task. Do not claim
control over an arbitrary task.

Use `dovet_open_console` to obtain the short-lived local pairing route when the user needs the
evidence UI. Never repeat, persist or send that route anywhere except the user's local browser.

Do not collect credentials, switch identities, rotate subscriptions, grant recovery approval,
expand scope, increase budget or report a worker claim as independently verified. The local
coordinator owns those decisions and retains checkpoint data after the plugin is removed.
